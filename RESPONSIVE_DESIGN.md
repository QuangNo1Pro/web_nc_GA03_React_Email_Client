# Responsive Design Guidelines

## Mobile (< 640px)
- Single column layout
- Touch-friendly buttons (min 44x44px)
- Simplified sidebar (hamburger menu)
- Font sizes: 14-16px
- Padding: 8-12px

## Tablet (640px - 1024px)
- Two column layout
- Mailbox sidebar + email list
- Medium font sizes: 16-18px
- Padding: 12-16px

## Desktop (> 1024px)
- Three column layout
- Expanded sidebar with labels
- Email detail pane
- Font sizes: 16-20px
- Padding: 16-24px

## Key Breakpoints
- sm: 640px
- md: 1024px
- lg: 1280px
- xl: 1536px

## Components Responsive
- Inbox header: Stacks on mobile
- Email list: Vertical scroll on mobile, horizontal on desktop
- Compose modal: Full screen on mobile, centered on desktop
- Sidebar: Toggle on mobile, always visible on desktop
